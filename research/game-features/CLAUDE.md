# Game features research

What FIFA/EA FC Career Mode and Football Manager offer (squad, tactics, transfers, finance, training, youth, objectives), and which we include in v1 vs later.

Done: `simulation-balance.md` (real big-five results against the match simulation, with `real_league_stats.py`), `overall-rating-formula.md` (how overall is built from attributes, weights per position, with `fit_overall.py`), `competition-formats.md` (league and cup formats, European places), `fixture-rescheduling.md` (how fixtures are made and moved). `domestic-cup-formats.md` (DFB-Pokal, Coppa Italia, Copa del Rey, EFL Cup). `european-places-by-season.md` (European places per country, 2014/15 to 2023/24).

Keep scope in mind: simulation only, M1-M5 first. Tag each feature `v1`, `later` or `skip`.
